# HU01 — Capturar o BDO por fotografia

**Persona:** Motorista

**Como** motorista,
**eu quero** fotografar o BDO recebido da companhia aérea,
**para que** os dados da entrega sejam registrados no sistema sem que eu precise digitá-los.

**Requisito(s) relacionado(s):** RF01

**Critérios de aceite:**
- Ao fotografar o BDO, o sistema deve extrair automaticamente os campos do padrão WorldTracer por OCR.
- Antes de confirmar o registro, devo ver uma tela de conferência com os valores sugeridos pelo OCR, podendo corrigi-los (RI01, RN01).
- A imagem original do BDO deve ficar anexada ao registro como prova documental (RD02).
- O registro só é salvo após minha confirmação explícita na tela de conferência.
